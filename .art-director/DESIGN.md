# DESIGN.md — CarusBrest, главная (демо)

> Закон для исполнителя. Отступать — только с объяснением в отчёте.

## Направление
**A «Кино TRX» + момент B «видео в буквах» + секция C «стена рилсов».** Смешанная основа: тёмные «кино»-главы на их роликах и светлый «бетон» между ними; широкий жирный гротеск как подписи в их рилсах; один акцент — жёлтый двойной сплошной американской дороги. Движение: кино (плавные раскрытия) + 3 громких места (бегущая строка, дым, штамп).
Собрано из: Hennessey (пикап на весь экран), Rivian (гигантская типографика вокруг машины), Rimac (кадр-окно раскрывается), McLaren (логотип рисуется), Hoonigan (строка, штамп, дым), Cars & Bids (живые карточки машин).

## Палитра
| Токен | Hex | Где |
|---|---|---|
| --ink | #0B0B0C | тёмные главы, текст на светлом |
| --coal | #151517 | футер, карточки на тёмном |
| --concrete | #D8D5CE | светлые главы (бетон) |
| --concrete-2 | #C9C5BC | подложки/рамки на бетоне |
| --paper | #EEECE7 | поля форм на бетоне |
| --yellow | #FFC629 | CTA, двойная линия, тикер-лента. Жёлтым фоном — только тикер-лента (1 место) |
| --white | #FFFFFF | текст на тёмном |

Не больше одного крупного жёлтого пятна на экран. Красного нет.

## Типографика
- Display: **Unbounded** 800/900, uppercase, letter-spacing −0.02em, line-height .92 (широкий, как «CARUS BREST / АВТО ИЗ США» в их рилсах).
- Text/UI: **Golos Text** 400/500/600/700.
- H1 clamp(56px, 9vw, 156px) — 2 строки максимум. H2 clamp(36px, 5.2vw, 84px). H3 22–26px Unbounded 700. Body 17px/1.55, small 14px.
- Наклейка (дрифт-приём): белая плашка, Unbounded 700 12–13px, радиус 8px, лёгкий наклон −2°.

## Пространство и сетка
Шаг 8px. Секции 140px desktop / 80px mobile. Контейнер 1360px, поля 40 / 16px. Радиусы: карточки 22px, поля и кнопки 14px.

## Разделение секций
Смена фона главами: ink (кино) → concrete (буквы) → yellow (лента) → ink (маршрут) → concrete (почему мы) → paper (привезли) → ink (автокультура, дым) → concrete (заявка) → coal (футер).

## Компоненты
- Кнопка основная: жёлтая, чёрный текст 700, h52, магнит к курсору ±6px, текст «прокатывается» на наведении.
- Вторичная: обводка 1.5px currentColor.
- Карточка-рилс: 9:16, радиус 22px, наклейка с моделью, подпись — их реальный текст из Instagram; видео играет в зоне видимости, ссылка на рилс.
- Двойная линия: два жёлтых штриха 4px с зазором 6px — фирменный разделитель и «дорога» маршрута.
- Форма: чипы выбора + телефон; после отправки — штамп «ЗАЯВКА ПРИНЯТА».

## Моушн (GSAP 3.12 + ScrollTrigger + Lenis)
1. Интро (только первый визит, ≤1.4 с): щит CB рисуется контуром (stroke-dashoffset) → заливка → две шторки уезжают, открывая видео.
2. H1 по словам снизу (yPercent 110 → 0), двойная линия «прорисовывается» слева направо.
3. Видео → буквы: пиннинг; то же видео TRX внутри букв CARUS BREST (canvas), буквы уменьшаются от «заливают экран» до размера слова на бетоне (scrub).
4. Тикер моделей: бесконечная лента, скорость и направление от скорости скролла.
5. Маршрут: кадр-окно (clip-path inset) раскрывается в полный экран; затем горизонтальная «трасса» этапов (desktop — пиннинг, mobile — вертикально), жёлтая разметка бежит под этапами.
6. «Почему мы»: слова в абзацах подсвечиваются по скроллу (opacity .15 → 1); фонарь-курсор на кадре СТО.
7. Одометр 12 200 подписчиков — барабанные цифры.
8. Дым-переход: видео бернаута (screen-режим) на входе в «Автокультуру».
9. Штамп после отправки формы.
prefers-reduced-motion — всё статично, интро нет, видео — постеры.

## Структура главной
1. Шапка: щит CB + CARUS BREST, «Как привозим / Почему мы / Привезли / Заявка», телефон, «Консультация».
2. Первый экран: видео TRX, H1 «Авто из США», «Подбор • Покупка • Доставка в Брест», карточка «Бесплатная консультация» (машина + телефон), справа сверху одометр Instagram.
3. Буквы CARUS BREST с видео + абзац позиционирования.
4. Лента моделей (их машины из рилсов).
5. Как привозим: Консультация → Подбор на аукционах США → Порт и море → Грузия, Поти → Автовоз до Бреста → Оформление и выдача. Без сроков и цен.
6. Почему мы: 4 пункта из шапки Instagram (Своё СТО / Бесплатные консультации / Официальное оформление / Полное сопровождение).
7. Привезли: стена рилсов с их подписями.
8. Автокультура: дрифт-видео + слова партнёров/подписчиков из Instagram.
9. Заявка: что ищете (тип), бюджет (необязательно), телефон → штамп.
10. Футер: телефон, Instagram, YouTube «CARUS AUTO», огромный щит.
